Abaqus Random Fiber Generator Plugin

A GUI plugin for automatically generating
randomly distributed fibers in Abaqus/CAE.

Features
- 2D / 3D fiber generation
- Random orientation
- Volume fraction control
- Periodic RVE support
- Automatic geometry creation

Supported versions
Abaqus 2021–2026
